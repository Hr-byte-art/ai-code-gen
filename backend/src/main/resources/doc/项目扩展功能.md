# 项目扩展功能建议

## 缓存与成本优化

### 1. 生成结果缓存
- **现状**：相同 prompt 会重复调用 AI，浪费 token
- **方案**：在 `AiCodeGeneratorService` 层增加基于 prompt hash 的结果缓存
- **收益**：节省 token 费用，提升响应速度

---

## 用户与商业化

### 2. 用户用量配额
- **现状**：仅有频率限制（`@RateLimit`），无 token/次数配额机制
- **方案**：添加每日/每月生成次数上限，支持 VIP 额度差异化
- **收益**：支撑商业化运营，防止滥用

### 3. 生成历史统计面板
- **现状**：有数据但缺少可视化统计
- **方案**：用户维度的生成次数、Token 消耗、应用类型分布等统计
- **收益**：提升用户体验，辅助运营决策

---

## 任务与通知

### 4. 异步任务持久化
- **现状**：`TaskCancellationManager` 仅在内存中管理取消状态，重启后丢失
- **方案**：用 Redis 存储任务状态，支持分布式部署
- **收益**：支持多实例部署，任务状态不丢失

### 5. WebSocket 实时通知
- **现状**：代码生成完成后只能轮询 `build/status`
- **方案**：增加 WebSocket 或 SSE 回调，实时推送构建结果给前端
- **收益**：提升用户体验，减少无效轮询

---

## 部署与运维

### 6. 多平台部署策略
- **现状**：`deployApp` 逻辑耦合在 Service 中
- **方案**：抽象部署策略接口，支持 Vercel / Netlify / 自建服务器等多平台
- **收益**：部署方式灵活可扩展

### 7. 蓝绿部署与版本回滚
- **现状**：部署后无法回滚
- **方案**：保留历史版本，支持一键回滚到指定版本
- **收益**：降低发布风险

---

## AI 能力增强

### 8. 多轮对话优化
- **现状**：对话历史存储在 Redis，但上下文利用有限
- **方案**：支持基于历史对话的增量修改（"把按钮改成蓝色"）
- **收益**：降低用户重新描述的成本

### 9. 代码模板库
- **现状**：每次从零生成
- **方案**：建立常用模板库（登录页、仪表盘、电商首页等），用户可基于模板定制
- **收益**：提升生成质量和速度

### 10. 生成质量评分
- **现状**：有质检节点但结果不展示给用户
- **方案**：将代码质量评分、可访问性评分等展示给用户
- **收益**：提升用户信任度，辅助用户选择最佳结果
