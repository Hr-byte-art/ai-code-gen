# 项目问题清单

## 安全漏洞

### 1. 路径遍历攻击
- **文件**：`StaticResourceController.java:56`
- **问题**：未对 `deployKey` 和 `resourcePath` 做路径穿越校验，攻击者可通过 `../../etc/passwd` 读取任意文件
- **修复**：使用 `Path.normalize()` 并校验结果是否在 `PREVIEW_ROOT_DIR` 内

### 2. CORS 配置过于宽松
- **文件**：`CorsConfig.java:17`
- **问题**：`allowedOriginPatterns("*")` + `allowCredentials(true)` 允许任意域携带 Cookie 发起请求，存在 CSRF 风险
- **修复**：限制为已知前端域名

### 3. AI 工具缺少路径校验
- **文件**：`FileWriteTool.java:30`、`FileReadTool.java:32`、`FileDeleteTool.java:28`、`FileModifyTool.java:32`
- **问题**：未对 AI 传入的路径做穿越校验，恶意 prompt 注入后可读写删除服务器任意文件
- **修复**：所有文件操作工具增加路径白名单校验

### 4. 命令注入风险
- **文件**：`VueProjectBuilder.java:125`
- **问题**：使用 `RuntimeUtil.exec` 执行拼接的命令字符串，`command.split("\\s+")` 在参数含空格时会出错
- **修复**：改用数组形式直接传参

### 5. 调试接口暴露
- **文件**：`AppController.java:341`
- **问题**：`/app/test/time` 接口无鉴权，暴露内部测试数据
- **修复**：生产环境应移除或加权限控制

## 代码缺陷

### 6. AuthInterceptor 冗余逻辑
- **文件**：`AuthInterceptor.java:47-53`
- **问题**：第 47 行已做 `equals(mustRole)` 判断，第 51 行对 ADMIN 的再次检查永远为 true，代码冗余且令人困惑
- **修复**：简化权限判断逻辑

### 7. UserController 暴露敏感字段
- **文件**：`UserController.java:124`
- **问题**：`/user/get` 直接返回 `User` 实体，包含密码哈希等敏感字段
- **修复**：返回脱敏的 VO 对象

### 8. SSE 错误信息泄漏
- **文件**：`AppController.java:401`
- **问题**：将 `error.getMessage()` 直接拼入 JSON 返回前端，可能泄漏堆栈路径等内部信息
- **修复**：返回通用错误提示，详细信息仅记录日志

### 9. 异常栈信息丢失
- **文件**：`AiCodeGeneratorFacade.java:145`
- **问题**：`catch` 块仅 `log.error("保存失败: {}", e.getMessage())`，丢失了异常栈信息
- **修复**：改为 `log.error("保存失败", e)`
